# Los textos

Todos los textos de la ROM, en inglés, menos el título, que son kanji en letras grandes. Las
letras son casillas del juego en el orden del ASCII (0x30-0x5F); en la pista, el espacio es
una casilla de hierba (0xE2-0xE4).

| Dónde | Texto | Qué dice |
|---|---|---|
| la selección (0x851A) | PLAYER SELECT | elige jugadores |
| | A PLAY-JOCKEY MODE | A: modo jinete |
| | B 1PLAYER BET MODE | B: apuesta un jugador |
| | C 2PLAYERS BET MODE | C: apuestan dos |
| | D 3PLAYERS BET MODE | D: apuestan tres |
| | E 4PLAYERS BET MODE | E: apuestan cuatro |
| | PUSH TRIGGER 1 TO START GAME | pulsa el botón 1 para empezar |
| | COPYRIGHT 1984 @ CASIO | la @ se dibuja como © y ^ como un guion |
| el recuadro (0x8794) | DEMONSTRATION | demostración, parpadeando |
| el recuadro (0x87E1) | 1ST BONUS 1000 / 2ND BONUS 500 | los premios del jinete; las cifras cambian con la carrera |
| la pista (0x888E) | HORSE SELECT JOY / START PUSH TRIG 2 | elige caballo con la palanca; el botón 2 sale |
| la pista (0x8AD9) | BET MODE | las apuestas |
| la pista (0x88A4) | PUSH TRIG 2 | pulsa el botón 2: la carrera siguiente |
| la pista (0x8C44) | GAME OVER | fin de la partida |
| la pista (0x8CAE) | RACE END | se acabaron las nueve carreras |

Las demás palabras están dibujadas en casillas propias (0xB835) y ya están en las
pantallas: ODDS (las cuotas) y las seis parejas, 1UP a 4UP, MIN y MAX en la barra de la
fuerza, RACE (carrera), GRASS (hierba) y DIRT (tierra) y las distancias en el óvalo, los
carteles de distancia de la pista, GOAL (meta) en el poste de la meta y un cartel de CASIO
entre los arbustos.

El título de la selección, CASIO y 大障害競馬 (*dai shōgai keiba*, «el gran premio de
obstáculos»), son 14 x 6 casillas (0xBD35).
